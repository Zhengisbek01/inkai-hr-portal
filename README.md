# МКА HR — HR-портал ТОО «МКА Инжиниринг»

React 18 + Vite 5. Один файл приложения: `src/hr-app.jsx`.

## Запуск локально
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

## Деплой на Vercel (отдельный проект)
1. Загрузите эту папку в новый репозиторий GitHub (например `mka-hr-portal`).
2. Vercel → Add New → Project → выберите репозиторий.
3. Framework Preset: **Vite** (определится сам). Root Directory — корень репозитория. Build: `npm run build`, Output: `dist`.
4. `vercel.json` не нужен.

## Что внутри
- Логотип МКА, 3 оформления (Промышленный / Светлый / Тёмный): выбор в «Мой профиль», значение по умолчанию — у администратора в «Управление».
- ҚАЗ / РУС: меню, заголовки, вход. Тексты внутри модулей пока на русском.
- Отделы: Руководство, Продажи, Закупки и ВЭД, Логистика и склад, Бухгалтерия.
- **Приказы**: 4 журнала (ОД, Л/С, К, АХ) со своей нумерацией за год; HR создаёт → директор подписывает (кнопка, ЭЦП NCALayer — этап 2) или возвращает с замечанием → сотрудники ознакамливаются (кнопка, ЭЦП — этап 2). PDF-файл (pdfmake, скачивается сразу) с подписью и листом ознакомления — только HR/директор. Экспорт журнала в Excel (CSV). Сотрудник видит приказ без скачивания/печати/копирования, с водяным знаком.
- **Учёт времени** (из timekeeper): Сегодня, Табель, Заявки, Работники, Отчёты, Киоски, Календарь. Отметка сканированием QR камерой телефона или по запасному коду (меняются каждые 30 с), опоздание после 5 мин, перерыв 1 ч при смене > 5 ч (ст. 81 ТК РК), праздники РК 2026.
- **Положения и правила**: 6 документов, редакции, ознакомление, лист ознакомления.

## Важно
- Данные хранятся в `localStorage` браузера — это демо-версия. Для работы нескольких пользователей нужен сервер (backend + БД, хранение ПДн в РК).
- Полностью запретить скриншот в браузере невозможно — водяной знак с ФИО и временем делает утечку отслеживаемой.
- QR: планшет показывает QR-код (библиотека qrcode), сотрудник сканирует его камерой телефона (jsQR); камера работает только по https (на Vercel — да). Запасной вариант — цифровой код под QR.
- ЭЦП (NCALayer) — следующий этап.
